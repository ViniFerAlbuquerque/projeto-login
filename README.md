<h1>Página de Login Responsiva!</h1>

<h2>-Descrição do Projeto:</h2>
<p>Este projeto consiste na implementação de uma tela de login moderna e responsiva, desenvolvida utilizando apenas HTML5 e CSS3. O objetivo principal foi criar uma interface de usuário agradável e funcional, que se adapta perfeitamente a diferentes tamanhos de tela (desktop, tablet e mobile), garantindo uma excelente experiência de usuário em qualquer dispositivo.

A página apresenta um formulário de login com campos para e-mail e senha, um botão para submissão e um link para recuperação de senha. Tudo isso é integrado a um design visualmente atraente, inspirado em temas de "saúde e transformação de vida", conforme a mensagem de boas-vindas aos usuários.</p>

<h2>-Funcionalidades:</h2>
<p>
  -Design Responsivo: Layout que se adapta automaticamente a diferentes larguras de tela (desktop, tablet, mobile) utilizando Media Queries.

-Formulário de Login Interativo: Campos de e-mail e senha com validação HTML (requerido, autocomplete, maxlength/minlength) e feedback visual ao focar.

-Ícones Visuais: Utilização de ícones do Google Material Icons para aprimorar a usabilidade e a estética dos campos de input e botões.

Animações e Transições: Efeitos suaves em elementos interativos (como botões e campos de input) para uma experiência de usuário mais fluida.

-Mensagens de Boas-Vindas: Textos convidativos que estabelecem o contexto do login.
</p>

<h2>-Tecnologias Utilizadas:</h2>
<p>
  -HTML5: Para a estrutura semântica e acessível da página.

-CSS3: Para toda a estilização e responsividade do projeto, incluindo cores, layout e animações.

-Google Material Icons: Biblioteca de ícones para elementos visuais no formulário.
</p>
